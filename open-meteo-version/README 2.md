# 箱根西麓 雨量モニター（Open-Meteo版）

芦ノ湖南側〜西側の山間部に近い3地点（箱根・御殿場・三島）の直近1時間降水量をオープンな気象データAPI「[Open-Meteo](https://open-meteo.com/)」から取得して表示し、最大値をもとに内水氾濫への注意度を判定する静的Webアプリです。

このフォルダは、気象庁アメダスを使う元のアプリ（リポジトリのルート）とは別に、データ取得元だけをOpen-Meteoに差し替えた**もう一つの独立したアプリ**です。判定基準や画面はルートのアプリと同じです。

## 判定基準

| 直近1時間降水量 | 表示 | 目安 |
| --- | --- | --- |
| 30 mm/h 以上 | 警戒 | 道路冠水や小河川の増水が始まる段階 |
| 20 mm/h 以上 | 注意 | 側溝や小規模な水路があふれ始める段階 |
| 20 mm/h 未満 | 平常 | 現時点で基準値未満 |

## 起動

ビルドは不要です。このフォルダを任意の静的HTTPサーバーで配信してください。

```bash
cd open-meteo-version
python3 -m http.server 4174
```

ブラウザで `http://localhost:4174` を開きます。観測値は Open-Meteo の Forecast API から直接取得し、10分ごとに自動更新します。

データ取得先は `https://api.open-meteo.com/v1/forecast` です。3地点（箱根・御殿場・三島）の緯度経度を指定し、現在時刻の降水量(mm/h相当)をまとめて取得しています。ブラウザまたは配信環境で外部ドメインを制限している場合は、`api.open-meteo.com` へのHTTPS通信を許可してください。

## 注意事項

- 表示は3地点の最大値であり、対象地域全域の雨量を保証するものではありません。
- Open-Meteo の値は気象予測モデルの格子点データであり、実測観測（アメダス）と差が生じることがあります。局地的な強雨を捉えられない場合があります。
- 避難判断には、自治体の避難情報や気象庁の防災情報も確認してください。

## テスト

```bash
cd open-meteo-version
node --test
```
