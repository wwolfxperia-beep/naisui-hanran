# 箱根西麓 雨量モニター

芦ノ湖南側〜西側の山間部に近い気象庁アメダス（箱根・御殿場・三島）の直近1時間降水量を表示し、最大値をもとに内水氾濫への注意度を判定する静的Webアプリです。

## 判定基準

| 直近1時間降水量 | 表示 | 目安 |
| --- | --- | --- |
| 30 mm/h 以上 | 警戒 | 道路冠水や小河川の増水が始まる段階 |
| 20 mm/h 以上 | 注意 | 側溝や小規模な水路があふれ始める段階 |
| 20 mm/h 未満 | 平常 | 現時点で基準値未満 |

## 起動

ビルドは不要です。任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。観測値は気象庁のアメダスJSONから直接取得し、10分ごとに自動更新します。

データ取得先は `https://www.jma.go.jp/bosai/amedas/data/map/` です。ブラウザまたは配信環境で外部ドメインを制限している場合は、`www.jma.go.jp` へのHTTPS通信を許可してください。公開直後のデータがまだ利用できない場合に備え、直近6件の10分値を新しい順に確認します。

## 注意事項

- 表示は3観測点の最大値であり、対象地域全域の雨量を保証するものではありません。
- アメダス観測点のない場所では、局地的な強雨を捉えられない場合があります。
- 避難判断には、自治体の避難情報や気象庁の防災情報も確認してください。
